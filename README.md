# УЗЕЛ — Wi-Fi Душ / сантехника из параллельной реальности

Многостраничный сатирический сайт с авторским визуальным языком инженерных чертежей. **Это демонстрационный дизайн-проект; услуги, кейсы, параметры и бренд вымышлены.**

## Запуск

Просто распакуйте архив и откройте `index.html` в браузере. Node.js, npm, сборка и backend не требуются.

Если браузер ограничивает некоторые функции на `file://`, запустите локальный сервер из папки проекта:

```powershell
py -m http.server 5500
```

Откройте `http://localhost:5500/`.

## Страницы

- `index.html` — главная, hero, каталог, процесс, галерея, CTA.
- `services.html` — каталог из 8 мемных услуг и фильтры.
- `wifi-shower.html` — продуктовая страница главной услуги, интерактивная симуляция подключения, настройка «влажности», FAQ.
- `projects.html` — вымышленные концепты, фотогалерея, интерактивное сравнение обработки снимка.
- `about.html` — манифест бренда и редакционный контент.
- `contacts.html` — форма составления демо-заявки, FAQ.
- `404.html` — оформленная страница ошибки.

## Файлы

- `assets/css/style.css` — все стили, дизайн-токены, адаптив, анимации.
- `assets/js/main.js` — мобильное меню, модальное окно, фильтры, симулятор, слайдеры, форма.
- `assets/img/*.svg` — локальные чертежи, иллюстрации и заглушки изображений.

## Изображения

Интерьерные фотографии подключены через **Unsplash (`images.unsplash.com`)** и для их загрузки нужен интернет. Это **стоковые иллюстрации**, не доказательства реализованных работ. Если изображение недоступно, JS подменит его локальной SVG-иллюстрацией.

Условия использования изображений: https://unsplash.com/license . Ссылки на исходные изображения находятся непосредственно в `src` HTML-страниц. Не подразумевается одобрение проекта авторами изображений. Перед коммерческим использованием стоит подобрать собственные фотоматериалы и повторно проверить права и доступность каждого изображения.

Шрифты подключаются с Google Fonts; при отсутствии сети используются системные замены.

## Поведение форм

Демо-форма **не отправляет** данные. Она формирует текст и пытается скопировать его в буфер обмена. Если браузер блокирует Clipboard API (например, при запуске с `file://`), текст выводится для ручного копирования. Ни телефон, ни адрес электронной почты не вымышлены.

## Проверено

Выполнена автоматизированная проверка рендеринга всех 6 основных страниц при ширинах 1440 / 768 / 390 / 320 px: горизонтальной прокрутки и ошибок JavaScript нет. Проверены фильтры, симуляция, форма, мобильное меню и окно. Браузерное окружение не имеет доступа к сторонним фотосерверам, поэтому локально проверялись SVG-заглушки вместо сетевых фотографий.

## Адаптация под реальный бизнес

Сейчас сайт специально сатирический. Если превращать его в реальный сервис, нужно заменить услуги, цены, документы и реальные контакты, добавить политику обработки персональных данных, backend/CRM для заявок и проверить фактические предложения до публикации.
